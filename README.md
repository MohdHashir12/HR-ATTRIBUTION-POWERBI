# HR & Attrition Dashboard 📊

This project presents an interactive **HR & Attrition Dashboard** built using **Power BI**. The dashboard analyzes employee data from a dataset of 1,233 records to uncover insights on workforce distribution, salary trends, job satisfaction, and attrition risks across departments and roles.

## 🔧 Tools & Technologies
- Power BI Desktop  
- DAX (Data Analysis Expressions)  
- Power Query  
- CSV (HR_Analytics.csv)

## 📌 Key Features
- Visual analysis of employee count, salary, job satisfaction, and attrition rates.
- Slicers for dynamic filtering by Department, Age Group, Gender, Education Field, Business Travel, and Job Role.
- Custom measures and KPIs:  
  - Average Salary: ₹6,879  
  - Attrition Rate: 16%  
  - Average Job Satisfaction: 2.78  
- Identified high-risk areas (e.g., Sales Representative with 39.76% attrition rate).

## 📁 Dataset
The dataset used (`HR_Analytics.csv`) includes fields such as:
- Age, Gender, Department, Job Role
- Monthly Income, Business Travel, Education Field
- Job Satisfaction, Attrition, OverTime

## 🚀 Getting Started
To view or edit the dashboard:
1. Download and open `HR & Attrition Dashboard.pbix` using Power BI Desktop.
2. Load the dataset from `HR_Analytics.csv` if needed.
3. Explore insights or modify visuals/measures as desired.
